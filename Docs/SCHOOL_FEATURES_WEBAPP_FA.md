# مدرسه — ویژگی‌های جدید برای وب‌اپ (سمت مشتری)

**مخاطب:** توسعه‌دهنده‌ی وب‌اپ (`webapp/`، Nuxt 4)، صفحه‌های مدرسه‌ی مشتری.
**تاریخ:** ۱۴۰۵/۰۸/۰۶ (2026-10-28)
**وضعیت بک‌اند:**
- مایگریشن روی دیتابیس **اجرا شده** است.
- کد Api **هنوز دیپلوی نشده** است. تا اعلام دیپلوی، اندپوینت‌های جدید ۴۰۴ و فیلدهای جدید `undefined` هستند. کد وب‌اپ باید نبودن فیلدها را تحمل کند (بند ۱۲).

**مستند هم‌زاد:** سمت ارائه‌دهنده (تعریف روزها، حضور و غیاب، مدرس‌ها، داشبورد) در `SCHOOL_FEATURES_NEMAYANDE_APP_FA.md` است و در وب‌اپ کاری ندارد.

---

## ۰) قواعد عمومی
- **الگوی فعلی وب‌اپ:** هر اندپوینت یک پراکسی Nuxt در `app/server/api/school/*.js` دارد (مثل `reserveCancel.put.js`) که توکن را از کوکی `token` می‌خواند و به `${baseUrl}/api/...` می‌فرستد. اندپوینت‌های جدید را **با همین الگو** اضافه کنید (فهرست در بند ۱۱)، و تابعشان را در `app/stores/useSchool.ts` بگذارید.
- **شکل پاسخ:** HTTP 200 با `{ isSuccess, messages: [{ item1 }], data }`. موفق بودن را از `isSuccess` تشخیص دهید و در خطا `messages[0].item1` را در toast نشان دهید.
- **مبلغ:** تومان است. با `schoolPrice()` فعلی قالب‌بندی کنید.

## ۱) صفحه‌ی دوره — `pages/school/course-[id].vue`
پاسخ `GET /api/SchoolCourse/{id}` (پراکسی `courseItem`) این فیلدهای جدید را دارد:

| فیلد | نوع | کار در صفحه |
|---|---|---|
| `level` | int | برچسب کنار نام دوره: ۱ «مقدماتی» (سبز)، ۲ «متوسط» (زرد)، ۳ «پیشرفته» (قرمز)؛ ۰ نمایش داده نشود |
| `prerequisiteCourseId` / `prerequisiteCourseName` | long؟ / string | یک کادر اطلاع: «پیش‌نیاز: پت شما باید دوره‌ی «{prerequisiteCourseName}» را کامل کرده باشد.» با لینک به `/school/course-{prerequisiteCourseId}` |
| `enrollPrice` | double | **قیمتی که الان پرداخت می‌شود.** در کادر «هزینه ثبت‌نام» به‌جای `price` همین را نشان دهید |
| `remainingSessions` | int | فقط وقتی `enrollPrice < price` |
| `lateEnrollmentMode` | int | ۰ بسته، ۱ قیمت کامل، ۲ نسبی (متن بند ۲) |
| `isRegistrationOpen` | bool | از قبل بود؛ حالا ثبت‌نام دیرهنگام را هم حساب می‌کند. دکمه‌ی ثبت‌نام را با همین کنترل کنید |
| `fullRefundHoursBeforeStart` / `lateCancelRefundPercent` | int | کادر «شرایط لغو» (بند ۳) |
| `certificateEnabled` | bool | نشان «🎓 همراه با گواهی پایان دوره» |
| `rateAvg` / `rateCount` | double / int | ستاره و «(۱۲ نظر)» زیر نام دوره، با لینک به بخش نظرها (بند ۸) |

### نمایش قیمت در ثبت‌نام دیرهنگام
اگر `enrollPrice < price`:
```
هزینه ثبت‌نام (هر پت)
~~۸۰۰٬۰۰۰~~  ۵۰۰٬۰۰۰ تومان
برای ۵ جلسه‌ی باقی‌مانده از ۸ جلسه
```
`enrollPrice` همان مبلغی است که سرور موقع ثبت‌نام می‌گیرد. خودتان حساب نکنید.

### دکمه‌ی اصلی پایین صفحه (منطق کامل)
| وضعیت | دکمه |
|---|---|
| `!isRegistrationOpen` | «ثبت‌نام بسته است» (غیرفعال، مثل الان) |
| ظرفیت پر (`full` فعلی) و کاربر در صف این دوره نیست | **«عضویت در لیست انتظار»** (بند ۴) |
| ظرفیت پر و کاربر در صف است | «در لیست انتظار هستید — نفر {position}» + لینک «خروج از صف» |
| باز و جا دارد | «ثبت‌نام در دوره» (مثل الان) |

## ۲) متن ثبت‌نام دیرهنگام
زیر کادر جلسه‌ها، وقتی جلسه‌ی اول گذشته ولی `isRegistrationOpen` هنوز `true` است:
- `lateEnrollmentMode = 1`: «دوره شروع شده است؛ هنوز می‌توانید با قیمت کامل ثبت‌نام کنید.»
- `lateEnrollmentMode = 2`: «دوره شروع شده است؛ فقط هزینه‌ی جلسه‌های باقی‌مانده را پرداخت می‌کنید.»

جلسه‌های گذشته را در لیست جلسه‌ها کم‌رنگ و با برچسب «برگزار شد» نشان دهید.

## ۳) شرایط لغو و لغو ثبت‌نام

### ۳-۱) کادر «شرایط لغو» در صفحه‌ی دوره
```
شرایط لغو
• تا {fullRefundHoursBeforeStart} ساعت قبل از شروع دوره: بازگشت کامل مبلغ به کیف پول
• کمتر از آن (تا قبل از شروع): بازگشت {lateCancelRefundPercent}٪
• بعد از شروع دوره امکان لغو وجود ندارد
```
- اگر `lateCancelRefundPercent = 100` بود، خط دوم را ننویسید.
- اگر `0` بود، بنویسید: «بازگشت وجه ندارد».

### ۳-۲) مودال لغو در `pages/school/reserve-[id].vue`
**متن فعلی مودال اشتباه است و باید عوض شود.** الان نوشته «بازگشت وجه به‌صورت خودکار انجام نمی‌شود». ولی سرور **خودکار** به **کیف پول** برمی‌گرداند (از قبل همین بود).

متن جدید، با محاسبه سمت وب‌اپ:
```js
// firstSessionStart = زمان شروع زودترین جلسه (تاریخ + startTime)
const hoursLeft = (firstSessionStart - Date.now()) / 36e5
const percent = !firstSessionStart ? 100
  : hoursLeft >= course.fullRefundHoursBeforeStart ? 100
  : course.lateCancelRefundPercent
const refund = Math.round(reserve.paymentPrice * percent / 100)
```
```
با لغو، {refund} تومان ({percent}٪ مبلغ پرداختی) به کیف پول شما برمی‌گردد و ظرفیت دوره آزاد می‌شود.
```
- اگر `percent < 100` بود، با رنگ هشدار اضافه کنید: «چون کمتر از {fullRefundHoursBeforeStart} ساعت به شروع مانده، فقط {percent}٪ برمی‌گردد.»
- **دکمه‌ی «لغو ثبت‌نام»:** فقط وقتی `state === 'paid'` **و جلسه‌ی اول هنوز شروع نشده** نشان دهید. بعد از شروع، سرور خطای «شما نمی توانید این رزرو را لغو کنید» می‌دهد.
- **مسیر لغو:** بدون تغییر، `PUT /api/EndUser/SchoolReserveCancel` (پراکسی `reserveCancel`).
- اگر `fullRefundHoursBeforeStart` در دیتای دوره نبود (سرور قدیمی)، همان ۱۰۰٪ را نشان دهید.

## ۴) لیست انتظار
### اندپوینت‌ها (با توکن)
| کار | بک‌اند | پراکسی پیشنهادی |
|---|---|---|
| لیست انتظارهای من | `GET /api/EndUser/SchoolLearning/Waitlist` | `waitlist.get.js` |
| عضویت | `POST /api/EndUser/SchoolLearning/Waitlist` با `{ "schoolCourseId": 12, "userPetId": 55 }` | `waitlistJoin.post.js` |
| خروج | `DELETE /api/EndUser/SchoolLearning/Waitlist?id=3` | `waitlistLeave.delete.js` |

پاسخ لیست (و پاسخ عضویت، تک‌آیتم):
```json
[ { "id": 3, "schoolCourseId": 12, "courseName": "تربیت پایه", "schoolName": "مدرسه استلا",
    "userPetId": 55, "petName": "رکس", "createDate": "...", "position": 2, "notifiedDate": null } ]
```

### جریان
1. ظرفیت پر است ← دکمه‌ی «عضویت در لیست انتظار».
2. انتخاب پت، با همان انتخاب‌گر پتِ فرم ثبت‌نام.
3. `POST` ← پیام موفقیت: «شما نفر {position} لیست انتظار هستید. اگر جایی خالی شود به شما خبر می‌دهیم.»
4. در صفحه‌ی دوره، با `GET` لیست انتظار ببینید آیا کاربر در صف همین دوره است (`schoolCourseId`)، و دکمه را طبق جدول بند ۱ نشان دهید.
5. **وقتی جا باز شود:** پوش «در دوره‌ی X جا باز شد» به **همه‌ی** افراد صف می‌رود و لینکش `/school/course-{id}` است. جا برای کسی نگه داشته نمی‌شود؛ هر کس زودتر ثبت‌نام کند، جا را می‌گیرد. با ثبت‌نام موفق، پت خودکار از صف بیرون می‌رود.

### خطاها
| پیام | وقتی |
|---|---|
| «این دوره هنوز جای خالی دارد؛ مستقیم ثبت‌نام کنید.» | دوره پر نیست؛ صفحه را دوباره بارگذاری کنید |
| «این پت قبلاً در لیست انتظار این دوره است.» | — |
| پیام «قبلاً پرداخت شده» | این پت از قبل در دوره ثبت‌نام دارد |

**صفحه‌ی «ثبت‌نام‌های من»** (`pages/reserve/index.vue`): یک زیربخش «لیست انتظار» با کارت هر آیتم (نام دوره، مدرسه، پت، جایگاه، دکمه‌ی خروج). یا ساده‌تر، یک کارت با `kind: 'school'` و وضعیت «در انتظار جا».

## ۵) پیش‌نیاز و سطح
- اگر پت پیش‌نیاز را نداشته باشد، **سرور** ثبت‌نام را رد می‌کند (`POST /api/EndUser/SchoolReserve`، پراکسی `reserve`) با پیام «این دوره پیش‌نیاز دارد؛ پت شما باید ابتدا دوره‌ی پیش‌نیاز را کامل کرده باشد.» همین را نشان دهید و دکمه‌ی «مشاهده‌ی دوره‌ی پیش‌نیاز» بگذارید.
- برچسب سطح را هم در صفحه‌ی دوره بگذارید و هم در کارت دوره در لیست دوره‌های مدرسه (`pages/school/school-[id].vue`).

## ۶) کارنامه‌ی پیشرفت پت (صفحه‌ی جدید)
### اندپوینت
`GET /api/EndUser/SchoolLearning/Report?reserveId=301` (فقط ثبت‌نام خود کاربر؛ وگرنه «موردی یافت نشد»). پراکسی پیشنهادی: `report.get.js`.

```json
{
  "schoolReserveId": 301, "courseName": "تربیت پایه", "petName": "رکس", "statusId": 2,
  "sessionCount": 4, "attendedCount": 3, "absentCount": 1, "attendancePercent": 75,
  "attendance": [
    { "schoolCourseSessionId": 88, "sessionDate": "2026-11-01T00:00:00", "startTime": "10:00", "present": true,  "note": null },
    { "schoolCourseSessionId": 89, "sessionDate": "2026-11-03T00:00:00", "startTime": "10:00", "present": false, "note": "اطلاع داد" },
    { "schoolCourseSessionId": 90, "sessionDate": "2026-11-05T00:00:00", "startTime": "17:00", "present": null,  "note": null }
  ],
  "skills": [
    { "skillId": 7, "skillName": "نشستن با فرمان", "latestScore": 4,
      "history": [ { "score": 2, "note": null, "schoolCourseSessionId": 88, "sessionDate": "...", "createDate": "..." },
                   { "score": 4, "note": "خیلی بهتر شد", "schoolCourseSessionId": 89, "sessionDate": "...", "createDate": "..." } ] }
  ],
  "certificate": null
}
```

### صفحه
- **مسیر پیشنهادی:** `pages/school/report-[id].vue` (`id` = شناسه‌ی ثبت‌نام).
- **ورود:** دکمه‌ی «کارنامه‌ی {نام پت}» در `pages/school/reserve-[id].vue`، فقط برای وضعیت پرداخت‌شده یا کامل‌شده.

**اجزای صفحه از بالا به پایین:**
1. سربرگ: نام پت + نام دوره.
2. **حضور:** دایره‌ی درصد `attendancePercent` و متن «{attendedCount} از {sessionCount} جلسه».
3. **لیست جلسه‌ها:** تاریخ شمسی (`schoolFaDate`) + ساعت + وضعیت:
   - `true` ✓ «حاضر» سبز
   - `false` ✗ «غایب» قرمز
   - `null` «ثبت نشده» خاکستری
   - یادداشت مدرس زیر ردیف
4. **مهارت‌ها:** برای هر مهارت نام + ۵ ستاره با `latestScore`، و یک نمودار خطی کوچک از `history` (محور افقی جلسه، عمودی نمره ۱ تا ۵). آخرین یادداشت مدرس هم زیرش.
   - اگر `skills` خالی بود: «مدرس هنوز مهارتی برای این دوره ثبت نکرده است.»
5. **گواهی:** اگر `certificate` پر بود، کارت بند ۷. اگر نبود و دوره `certificateEnabled` دارد: «گواهی بعد از تکمیل دوره صادر می‌شود.»

## ۷) گواهی پایان دوره
### داده (داخل کارنامه یا استعلام)
```json
{ "code": "PSC-7KQ2MX9A", "issueDate": "2026-11-20T…", "courseName": "تربیت پایه", "courseLevel": 1,
  "schoolName": "مدرسه استلا", "petName": "رکس", "ownerFullName": "علی رضایی", "sessionCount": 4, "attendedCount": 4 }
```

### ۷-۱) کارت گواهی (در کارنامه)
- طرح یک گواهی با نام پت (بزرگ)، «با موفقیت دوره‌ی {courseName} را در {schoolName} به پایان رساند»، سطح، تاریخ صدور شمسی، «حضور: {attendedCount} از {sessionCount} جلسه»، و کد گواهی.
- **QR** لینک استعلام: `https://{دامنه‌ی وب‌اپ}/school/certificate-{code}`.
- دکمه‌ها:
  - «دانلود تصویر»: با `html2canvas` یا Canvas خودتان. **سرور PDF نمی‌سازد.**
  - «اشتراک‌گذاری»: Web Share API با متن و لینک استعلام.

### ۷-۲) صفحه‌ی عمومی استعلام (صفحه‌ی جدید، بدون ورود)
- **مسیر:** `pages/school/certificate-[code].vue`. این همان مسیری است که پوش «گواهی صادر شد» باز می‌کند.
- **اندپوینت عمومی:** `GET /api/School/Certificate/{code}` (بدون توکن؛ حروف بزرگ و کوچک فرقی ندارد). پراکسی: `certificate.get.js`.
- **موفق:** همان طرح کارت با نشان «✔ گواهی معتبر است».
- **ناموفق:** «گواهی با این کد پیدا نشد.»
- یک فیلد «کد گواهی را وارد کنید» هم برای استعلام دستی بگذارید.

## ۸) امتیاز و نظر برای دوره
### ۸-۱) ثبت امتیاز (با توکن)
`POST /api/EndUser/SchoolLearning/Rate` با بدنه‌ی `{ "schoolReserveId": 301, "rate": 5, "text": "عالی بود" }`. پراکسی: `rate.post.js`.
- فقط برای ثبت‌نام **«کامل‌شده»** (`statusId = 3`)، وگرنه «موردی یافت نشد».
- `rate` از ۱ تا ۵ است، و `text` اختیاری تا ۱۰۰۰ نویسه.
- **یک نظر برای هر ثبت‌نام.** ارسال دوباره همان را ویرایش می‌کند.
- **محل UI:** در `pages/school/reserve-[id].vue` برای ثبت‌نام کامل‌شده، کارت «به این دوره امتیاز دهید» با ۵ ستاره و جعبه‌ی متن.
- پیشنهاد: بعد از کامل شدن، اولین بار که کاربر صفحه را باز می‌کند مودال امتیازدهی خودکار باز شود. برای هر ثبت‌نام یک بار؛ با `localStorage` نگه دارید.

### ۸-۲) نمایش نظرها (عمومی، بدون توکن)
`GET /api/School/Course/{courseId}/Rates?take=50`. پراکسی: `courseRates.get.js`.
```json
[ { "id": 9, "schoolCourseId": 12, "rate": 5, "text": "عالی بود", "answer": null, "userFullName": "علی رضایی", "createDate": "..." } ]
```
- در صفحه‌ی دوره، بخش «نظرات شرکت‌کنندگان»: میانگین `rateAvg` بزرگ + تعداد، و لیست نظرها.
- نظرهای ردشده توسط ادمین نمی‌آیند.
- اگر `answer` پر بود، «پاسخ مدرسه» را زیر نظر نشان دهید.

## ۹) پوش‌ها (Web Push) و مسیرها
این‌ها را سرور خودش می‌فرستد. فقط مطمئن شوید مسیرها در وب‌اپ وجود دارند:

| نوع | عنوان | لینک | صفحه در وب‌اپ |
|---|---|---|---|
| 169 | «در دوره‌ی {0} جا باز شد» | `/school/course-{id}` | موجود |
| 170 | «فردا کلاس دارید» | `/school/course-{id}` | موجود |
| 171 | «جلسه را از دست دادید» | `/school/course-{id}` | موجود |
| 172 | «گواهی پایان دوره صادر شد» | `/school/certificate-{code}` | **جدید، بند ۷-۲** |

برای ۱۷۱ پیشنهاد می‌شود اگر کاربر در صفحه‌ی دوره ثبت‌نام دارد، بالای صفحه لینک «کارنامه‌ی من» را برجسته کنید.

## ۱۲) سازگاری تا قبل از دیپلوی Api
- همه‌ی فیلدهای جدید ممکن است `undefined` باشند:
  - `enrollPrice ?? price`
  - `level || 0`
  - `rateCount || 0`
  - `fullRefundHoursBeforeStart ?? null` (اگر null بود، متن قدیمیِ ۱۰۰٪)
- اگر پراکسی جدید ۴۰۴ داد، بخش مربوط را پنهان کنید و خطا ندهید.

## ۱۳) چک‌لیست تست (بعد از اعلام دیپلوی)
1. صفحه‌ی دوره: برچسب سطح، «همراه با گواهی»، کادر شرایط لغو با عددهای درست.
2. دوره با `lateEnrollmentMode = 2` بعد از جلسه‌ی اول: قیمت خط‌خورده + `enrollPrice` ← ثبت‌نام ← پرداخت با همان مبلغ.
3. دوره با `lateEnrollmentMode = 0` بعد از شروع: «ثبت‌نام بسته است».
4. دوره‌ی پر: «عضویت در لیست انتظار» ← انتخاب پت ← «نفر ۱» ← بازگشت به صفحه: «در لیست انتظار هستید».
5. یک ثبت‌نام دیگر لغو شود ← پوش «جا باز شد» ← کلیک ← صفحه‌ی دوره ← ثبت‌نام ← آیتم از لیست انتظار حذف شود.
6. دوره با پیش‌نیاز و پت بدون پیش‌نیاز ← پیام پیش‌نیاز + لینک دوره‌ی پیش‌نیاز.
7. لغو ۴۸ ساعت قبل: مودال «۱۰۰٪» ← کیف پول کامل شارژ شود. لغو ۱۰ ساعت قبل: مودال «۵۰٪» با هشدار ← کیف پول نصف.
8. کارنامه: حضور، غیاب و ثبت‌نشده درست؛ ستاره‌ها و نمودار مهارت.
9. ثبت‌نام کامل‌شده ← پوش گواهی ← صفحه‌ی استعلام «معتبر» ← کد اشتباه ← «پیدا نشد».
10. دانلود تصویر گواهی و QR آن.
11. امتیاز ۵ با متن ← در صفحه‌ی دوره میانگین و نظر دیده شود ← ویرایش امتیاز ← میانگین عوض شود.
12. ثبت‌نام پرداخت‌شده (نه کامل‌شده) ← کارت امتیاز نباید باشد.
