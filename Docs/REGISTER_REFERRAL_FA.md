# فرایند منبع آشنایی و کد معرف در ثبت‌نام

## Endpoint

```http
POST /api/Account/signup
```

DTO ورودی این Endpoint کلاس `SignUpDto` است.

## فیلدهای جدید

| فیلد | نوع | توضیح |
|---|---:|---|
| `referralSource` | number | نحوه آشنایی کاربر با پاستیل |
| `referralCode` | string / null | کد معرف واردشده توسط کاربر |

مقادیر `referralSource`:

| مقدار | عنوان |
|---:|---|
| `0` | مشخص‌نشده؛ فقط برای سازگاری با نسخه‌های قدیمی |
| `1` | کلینیک |
| `2` | پت‌شاپ |
| `3` | آشنایان |
| `4` | شبکه اجتماعی |
| `5` | سایر |

## منطق نمایش فرم

- برای `1`، `2` و `3` فیلد کد معرف نمایش داده شود و اجباری است.
- برای `4` و `5` فیلد کد معرف نمایش داده نشود و مقدار `null` ارسال شود.
- ورودی کد فقط عددی باشد.
- کد کلینیک و پت‌شاپ دقیقاً ۱۰ رقم است.
- کد معرف کاربر فعلاً دقیقاً ۷ رقم است.

## اعتبارسنجی بک‌اند

- `Clinic` فقط کد Companion فعال و تأییدشده را قبول می‌کند.
- `PetShop` فقط کد Store فعال را قبول می‌کند.
- `Acquaintances` فقط کد User فعال و قفل‌نشده را قبول می‌کند.
- انتخاب یک نوع و ارسال کد نوع دیگر نامعتبر است.
- کاربر نمی‌تواند کد معرف متعلق به موبایل یا ایمیل خودش را وارد کند.
- مالک Companion نمی‌تواند کد همان Companion را وارد کند.
- کاربران متصل به Store نمی‌توانند کد همان Store را وارد کنند.
- برای شبکه اجتماعی و سایر، هر کد ارسالی نادیده گرفته می‌شود.

## کد اختصاصی کسب‌وکارها

- کد Companion ده‌رقمی و با رقم `1` شروع می‌شود.
- کد Store ده‌رقمی و با رقم `2` شروع می‌شود.
- پانسیون کد جدا ندارد و از کد Companion مالک خود استفاده می‌کند.
- کدهای جدید با مولد رمزنگاری‌شده ساخته می‌شوند.
- Unique Index دیتابیس مانع ثبت کد تکراری می‌شود.
- Migration برای Companion و Storeهای موجود نیز کد تصادفی و یکتا تولید می‌کند.

## فیلدهای ذخیره‌شده برای User

| فیلد | کاربرد |
|---|---|
| `ReferralCode` | کد اختصاصی خود کاربر |
| `RegistrationReferralSource` | منبع آشنایی انتخاب‌شده |
| `UsedReferralCode` | کدی که هنگام ثبت‌نام مصرف شده |
| `ReferredByUserId` | شناسه کاربر معرف در حالت آشنایان |
| `ReferredByCompanionId` | شناسه Companion معرف در حالت کلینیک |
| `ReferredByStoreId` | شناسه Store معرف در حالت پت‌شاپ |

در هر ثبت‌نام حداکثر یکی از سه شناسه معرف مقدار خواهد داشت.

## امتیازدهی بعد از ثبت‌نام

- در معرفی توسط کاربر، هم کاربر معرف و هم کاربر جدید امتیاز می‌گیرند.
- در معرفی توسط کلینیک یا پت‌شاپ، هم مالک کسب‌وکار و هم کاربر جدید امتیاز می‌گیرند.
- امتیاز پیش‌فرض هر طرف `100` است و از قوانین امتیاز پنل مدیریت می‌شود.
- تراکنش‌ها Idempotent هستند و برای یک ثبت‌نام دوباره ثبت نمی‌شوند.
- Eventهای مربوط به معرف، کاربر جدید و معرفی کسب‌وکار به‌ترتیب `6`، `7` و `8` هستند.
