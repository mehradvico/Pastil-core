# روش‌های ارسال با قیمت فروشگاه — مستند اپ نماینده/فروشنده (اپ‌نویس)

تاریخ: ۱۳ آبان ۱۴۰۵ — endpointها همان قبلی‌اند (`api/Seller/Delivery`)؛ فقط قواعد اعتبارسنجی و یک نوع ارسال جدید اضافه شد.

## ۱. انواع ارسال
`GET api/Seller/Delivery/types` حالا این‌ها را هم برمی‌گرداند (بعد از اجرای SQL `StorePricedShippingMethods.sql`): **پست، تیپاکس، ماهکس (جدید)، الوپیک** (کد `Label`: `DeliveryType_Post / _Tipax / _Mahex / _AloPeyk`). این چهار «روش با قیمت فروشگاه» هستند. فهرست را از همین endpoint بگیرید و ثابت ننویسید.

## ۲. فرم تعریف روش (POST/PUT `api/Seller/Delivery`)
برای این چهار نوع:
- `shippingProvider` = `0` (None) و `livePricing = false`؛ غیر از این خطا می‌آید. در فرم این دو را نمایش ندهید و ثابت بفرستید.
- یکی از دو حالت:
  - **کرایه ثابت**: `afterRent=false`، `basePrice > 0` (تومان)، `allowPrepaid=true` (کرایه همراه سفارش از مشتری گرفته می‌شود).
  - **پس‌کرایه**: `afterRent=true` (کرایه با گیرنده؛ `basePrice` سمت سرور ۰ می‌شود، فیلد قیمت را مخفی/غیرفعال کنید). `allowReceiverPay` را `true` بفرستید.
  - بدون قیمت و بدون پس‌کرایه → خطای «مبلغ را وارد کنید یا پس‌کرایه بگذارید».
- ارسال رایگان بالای مبلغ/تعداد (`minPriceForFree`, `minCountForFree`) مثل قبل اختیاری است.
- `maxDays` = حداکثر روز تحویل (برای نمایش به مشتری).
- هیچ‌چیز مربوط به شهر برای پست/تیپاکس/ماهکس لازم نیست؛ خالی = کل کشور. می‌توانید با `stateId/cityId` محدودش کنید.

### الوپیک
- فقط تهران: اگر `cityId` یا `stateId` می‌فرستید باید «تهران» باشد، وگرنه خطای «الوپیک فقط برای تهران قابل تعریف است». پیشنهاد UI: شهر را روی «تهران» قفل کنید.
- در سمت مشتری فقط برای آدرس‌های شهر تهران دیده می‌شود.

## ۳. اثر روی مشتری (برای فهم رفتار)
- آدرس تهران و فروشگاه الوپیک فعال دارد ← فقط الوپیک (به‌علاوه پیک پاستیل/حضوری)؛ پست/تیپاکس/ماهکس پنهان.
- آدرس غیر تهران ← الوپیک هرگز؛ پست/تیپاکس/ماهکس همیشه.
- پس‌کرایه: مبلغی از مشتری گرفته نمی‌شود؛ کرایه را گیرنده هنگام تحویل می‌دهد.
پس اگر فروشنده می‌خواهد کل کشور پوشش بدهد: الوپیک (تهران) + حداقل یک از پست/تیپاکس/ماهکس تعریف کند. در UI یک راهنمای کوتاه همین را بنویسید.

## ۴. خطاهای جدید (فارسی، در `messages[0].item1`)
- روش قیمت‌گذاری فروشگاه نباید لحظه‌ای/ارائه‌دهنده داشته باشد.
- مبلغ کرایه را وارد کنید یا پس‌کرایه بگذارید.
- الوپیک فقط برای تهران قابل تعریف است.
مستقیم نمایش دهید.

## ۵. پیش‌نیاز استقرار
اول SQL `scripts/StorePricedShippingMethods.sql` (ماهکس را می‌سازد و تیپاکس/الوپیک را فعال می‌کند)، بعد دیپلوی Api.
