# هدیه‌ی ۲۰۰ هزار تومانی تکمیل پروفایل پت — راهنمای وب‌اپ و اپ

تاریخ: ۱۴۰۵/۰۸/۲۳ · بک‌اند: ساخته‌شده · دیتابیس اصلی: اعمال‌شده (`scripts/AutomationPhase0.sql`) · وب‌اپ/اپ: **باید ساخته شود**

## رفتار
- پیامک خوش‌آمد ثبت‌نام (قالب کاوه‌نگار `UserSignUp`) به کاربر می‌گوید با تکمیل پروفایل پتش ۲۰۰ هزار تومان اعتبار خرید می‌گیرد و لینک `https://app.pastil.pet/pet/add` را دارد.
- وقتی **اولین پتی که کاربر ثبت کرده** کامل شود (موقع ثبت یا بعداً با ویرایش)، بک‌اند یک «پیشنهاد کلاب» رایگان برایش می‌سازد و پوش `PushClubPetProfileGift` (۱۷۵، لینک `/club`) می‌فرستد.
  - «کامل» = نام، نوع پت، **عکس**، نژاد اصلی، تاریخ تولدی که در آینده نیست. نژاد دوم (دورگه) **لازم نیست** (به‌روزرسانی ۱۴۰۵/۰۸/۲۴: فرم وب‌اپ فیلد نژاد دوم ندارد).
  - عکس در فرم وب‌اپ اختیاری است ولی برای هدیه لازم است؛ بنر باید آن را بگوید (فیلد `missingFields`).
  - پت‌های دوم به بعد هدیه ندارند. هر کاربر فقط یک‌بار (حتی اگر پت اول را حذف کند).
- هدیه **۳۰ روز از لحظه‌ی تکمیل پروفایل** اعتبار دارد (نه از لحظه‌ی فعال کردن).
- کاربر در کلاب دکمه‌ی **«فعال کن»** را می‌زند → ۲۰۰ هزار تومان «اعتبار تشویقی» ساخته می‌شود با **همان تاریخ انقضا**.
- اعتبار همه‌جا (فروشگاه و همه‌ی رزروها) خرج می‌شود، سقف ندارد و می‌شود تکه‌تکه خرجش کرد. باقی‌مانده تا انقضا می‌ماند.

## APIها
همه با توکن کاربر. پاسخ‌ها مثل بقیه `{ isSuccess, code, messages, data }` هستند؛ همیشه `isSuccess` را چک کنید.

### ۰. وضعیت هدیه برای بنر و کارت (جدید، ۱۴۰۵/۰۸/۲۴)
`GET /api/EndUser/PetProfileGift`

یک درخواست کافی است تا بدانید چه چیزی نشان دهید. نمونه‌ی `data`:
```json
{
  "status": 2, "statusKey": "Incomplete", "showBanner": true,
  "amount": 200000, "firstUserPetId": 57, "missingFields": ["picture", "breed"],
  "offerId": null, "expiresAt": null, "creditRemaining": null, "creditExpiresAt": null
}
```
| `status` | `statusKey` | چه نشان دهید |
|---|---|---|
| 0 | `Unavailable` | هیچ‌چیز (هدیه در کلاب غیرفعال است) |
| 1 | `NoPet` | بنر «پتت رو اضافه کن و ۲۰۰ هزار تومان اعتبار بگیر» → `/pet/add` |
| 2 | `Incomplete` | بنر «پروفایل پتت رو کامل کن» + فهرست `missingFields` → ویرایش پت `firstUserPetId` |
| 3 | `SaveToClaim` | پت اول کامل است ولی قبل از راه‌اندازی هدیه کامل شده؛ بنر «پروفایل پتت رو یک بار ذخیره کن تا هدیه‌ت فعال بشه» → ویرایش پت `firstUserPetId` |
| 4 | `Ready` | کارت هدیه با شمارش معکوس تا `expiresAt` و دکمه‌ی «فعال کن» (`offerId`) |
| 5 | `Activated` | «فعال شد»: مانده `creditRemaining` تا `creditExpiresAt` |
| 6 | `Expired` | «منقضی شد» (یا هیچ‌چیز) |
| 7 | `NotEligible` | هیچ‌چیز (پت اول حذف شده و هدیه‌ای نگرفته) |

- `showBanner` فقط برای ۱ تا ۳ `true` است. **بنر را فقط با همین فیلد نشان دهید**، نه با بررسی پت‌ها در کلاینت.
- کاربری که هدیه را گرفته و بعد پت اولش را حذف کرده همچنان `Ready`/`Activated`/`Expired` می‌گیرد، پس بنر دوباره ظاهر نمی‌شود.
- کلیدهای `missingFields`: `name` (نام)، `petType` (نوع حیوان)، `picture` (عکس)، `breed` (نژاد)، `birthday` (تاریخ تولد).
- بعد از ذخیره‌ی پت یا «فعال کن»، این API را دوباره بخوانید.

### ۱. فهرست پیشنهادهای کلاب کاربر
`GET /api/EndUser/PastilClubRewardOffer?pageIndex=1&pageSize=20`

هدیه را این‌طور تشخیص دهید: `templateName == "PetProfileGift"` (یا `pointCost == 0`).

فیلدهای مهم هر آیتم:
| فیلد | معنی |
|---|---|
| `id` | شناسه‌ی پیشنهاد؛ برای فعال کردن لازم است |
| `title` / `shortDescription` / `description` / `terms` | متن‌ها (از پنل قابل ویرایش) |
| `rewardType` | `4` = اعتبار تشویقی کیف پول |
| `benefitValue` | `200000` (تومان) |
| `pointCost` | `0` |
| `expiresAt` | تاریخ انقضا (UTC، DateTimeOffset) |
| `status` | `2` = آماده‌ی فعال‌سازی، `4` = فعال‌شده، `5` = منقضی |
| `canRedeem` | `true` یعنی دکمه‌ی «فعال کن» فعال باشد |

### ۲. فعال کردن هدیه
`POST /api/EndUser/PastilClubRewardRedeem`
```json
{ "rewardOfferId": 123 }
```
- موفق: `data.pointSpent == 0`، `data.expiresAt` = همان انقضای پیشنهاد.
- چندبار زدن بی‌خطر است (اعتبار دوم ساخته نمی‌شود).
- خطاهای ممکن در `messages`: `CLUB_REWARD_EXPIRED`، `CLUB_REWARD_NOT_FOUND`، `CLUB_REWARD_NOT_APPROVED`.

### ۳. اعتبارهای فعال کاربر (برای کیف پول و صفحه‌ی پرداخت)
`GET /api/EndUser/PastilClubBenefit` (`includeConsumed=true` برای دیدن مصرف‌شده‌ها)

در `data.promotionalCredits`: `rewardTitle`، `originalAmount`، `remainingAmount`، `expiresAt`، `status` (`1` فعال، `2` مصرف‌شده، `3` منقضی).

## چیزهایی که وب‌اپ/اپ باید نشان دهد
1. **کارت هدیه در صفحه‌ی کلاب** (بالای فهرست جوایز، متمایز):
   - عنوان، «۲۰۰٬۰۰۰ تومان»، برچسب «رایگان» به‌جای «۰ امتیاز».
   - **شمارش معکوس**: «X روز تا انقضا» (روز آخر: «فقط تا امشب» / ساعت باقی‌مانده). از `expiresAt` حساب شود و به وقت تهران نمایش داده شود.
   - تاریخ انقضا به شمسی: «معتبر تا ۲۳ آذر ۱۴۰۵».
   - دکمه‌ی **«فعال کن»** → API شماره‌ی ۲ → پیام موفقیت «۲۰۰ هزار تومان به اعتبار خریدت اضافه شد» و رفرش.
   - بعد از فعال‌سازی کارت به حالت «فعال شد» برود و مانده‌ی اعتبار + روزهای باقی‌مانده را نشان دهد (از API شماره‌ی ۳).
   - منقضی‌شده: خاکستری، «منقضی شد»، بدون دکمه.
2. **کیف پول**: زیر موجودی نقدی، ردیف «اعتبار هدیه: ۱۸۰٬۰۰۰ تومان · ۱۲ روز مانده» (از API شماره‌ی ۳).
3. **صفحه‌ی پرداخت/سبد**: اگر اعتبار فعال دارد، نشان دهید که از آن کم می‌شود (منطق کسر در بک‌اند موجود است).
4. **بنر «پروفایل پتت رو کامل کن»** در پروفایل/کلاب: فقط وقتی `showBanner` در API شماره‌ی ۰ برابر `true` است، با متن مناسب `status` و فیلدهای ناقص.
5. **پوش ۱۷۵** روی `/club` باز می‌شود؛ صفحه‌ی کلاب باید کارت هدیه را بالا نشان دهد.

## پنل ادمین
قالب `PetProfileGift` در فهرست قالب‌های کلاب دیده می‌شود. متن‌ها را می‌شود ویرایش کرد. امتیاز صفر فقط وقتی پذیرفته می‌شود که «پیشنهاد خودکار» و «دستی» هر دو خاموش باشند (وگرنه جایزه‌ی مجانی همگانی می‌شد).
