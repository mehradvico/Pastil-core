# API «موجود شد خبرم کن» محصول

این قابلیت جدا از `ProductLike` است و برای هر کاربر و محصول فقط یک درخواست فعال نگه می‌دارد.

## APIها

همه مسیرها نیاز به Bearer Token دارند:

- `GET /api/EndUser/ProductStockAlert?productId={productId}`: وضعیت درخواست کاربر برای محصول را برمی‌گرداند. برای بررسی وجود درخواست فعال، مقدار `data` یا آیتم متناظر با `productId` را بررسی کنید.
- `POST /api/EndUser/ProductStockAlert`: ثبت/فعال‌کردن درخواست.

```json
{ "productId": 123 }
```

- `DELETE /api/EndUser/ProductStockAlert`: لغو درخواست.

```json
{ "productId": 123 }
```

`UserId` در بدنه قابل اعتماد نیست و بک‌اند آن را از کاربر لاگین‌شده تعیین می‌کند. پاسخ موفق دارای `isSuccess: true` است.

## رفتار فرانت

وقتی هیچ آیتم فعال برای محصول وجود ندارد و موجودی محصول صفر است، دکمه «موجود شد خبرم کن» نمایش داده شود. بعد از پاسخ موفق، دکمه به «درخواست ثبت شد» تغییر کند و امکان لغو هم وجود داشته باشد. پس از لغو، دکمه دوباره به حالت اولیه برگردد.

موجودی زمانی «موجود» محسوب می‌شود که حداقل یک `ProductItem` همان محصول در یک فروشگاه مقدار `quantity > 0`، فعال و قابل‌فروش داشته باشد.

## Push

پس از عبور موجودی یک تنوع محصول از صفر به مقدار مثبت، برای همه درخواست‌های فعال همان محصول یک Push ارسال می‌شود و درخواست‌ها مصرف‌شده می‌شوند. متن Push:

`Name عزیز، پت‌شاپ XXXX کالای XXX که منتظرش بودی را موجود کرد.`

لینک Push به `/product/{productId}` می‌رود. اگر کاربر بعد از دریافت اعلان دوباره منتظر موجودی باشد، می‌تواند درخواست جدید ثبت کند.

برای فعال‌سازی Push، اسکریپت زیر را یک‌بار روی دیتابیس اجرا کنید:

`scripts/database/AddProductStockAlertPush.sql`

و Migration زیر را روی محیط اجرا اعمال کنید:

`20260823113000_AddProductStockAlerts`
