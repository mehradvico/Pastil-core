راهنمای اسکن قلاده‌ی هوشمند (PetTag QR)

این مستند برای پیاده‌سازی بخش اسکن QR قلاده در وب‌اپه — از لحظه‌ی اسکن تا اتصال کد به پت یا نمایش پروفایل پت گم‌شده. آدرس پایه: https://api.pastil.pet

نقطه‌ی شروع همیشگی GET /api/PetTagPublic/{code} — عمومی، بدون نیاز به لاگین
اسکن QR روی قلاده → صفحه‌ی tag/{code}
↓
GET /api/PetTagPublic/{code}
↓
claimed = false
فلوی اتصال کد به یکی از پت‌های کاربر
claimed = true
نمایش مستقیم پروفایل عمومی پت

۱. استعلام وضعیت کد

GET /api/PetTagPublic/{code}
حالت الف — هنوز اتصال نخورده 
{
  "isSuccess": true,
  "data": { "claimed": false, "pet": null }
}
حالت ب — قبلاً به یک پت وصل شده 
{
  "isSuccess": true,
  "data": {
    "claimed": true,
    "pet": {
      "name": "لوکی",
      "breedName": "پامرینین",
      "isMale": true,
      "pictureUrl": "https://file.pastil.pet/...",
      "ownerFirstName": "علی",
      "ownerLastName": "رضایی",
      "ownerMobile": "09123456789"
    }
  }
}

۲. فلوی اتصال (وقتی claimed = false)

کاربر لاگین نیست

ببرش صفحه‌ی ورود/ثبت‌نام. حتماً code رو نگه دار (query param یا sessionStorage) تا بعد از لاگین موفق، دوباره برگردونیش همین‌جا.

کاربر لاگین است

باید ازش بپرسی این کد رو به کدوم پتش وصل کنه — سه قدم پایین رو دنبال کن.

۱ لیست پت‌های کاربر رو بگیر
GET /api/EndUser/UserPet

پاسخ توی data.list — هرکدوم حداقل id و name داره.

۲ لیست پت‌هایی که از قبل کد دارن رو بگیر
GET /api/EndUser/PetTag/mine 
{
  "isSuccess": true,
  "data": [
    { "userPetId": 41, "code": "B7K2...", "claimedDate": "2026-08-20T10:00:00" }
  ]
}
قانون مهم: هر پت فقط و فقط یک‌بار، برای همیشه می‌تونه به یک کد وصل بشه — دیگه هیچ‌وقت کد دومی قبول نمی‌شه، حتی اگه کد اولی گم شده باشه. هر پتی که idش توی این لیست باشه رو توی فرم انتخاب غیرفعال کن — بک‌اند هم مستقل همین قانون رو چک می‌کنه، ولی تجربه‌ی کاربری بهتره از همون اول جلوش گرفته بشه.
۳ بعد از انتخاب پت، وصلش کن
POST /api/EndUser/PetTag/claim 
{ "code": "A2K9XQZ7...", "userPetId": 41 }
پاسخ موفق 
{ "isSuccess": true, "data": null }

بعدش کاربر رو ببر به پروفایل پتش (بخش ۳).

۳. نمایش پروفایل عمومی پت (وقتی claimed = true)

همون داده‌ای که از بخش ۱ گرفتی رو مستقیم نشون بده — نیازی به درخواست یا لاگین دیگه‌ای نیست.

این صفحه باید بدون لاگین برای همه باز بشه — کسی که قلاده رو پیدا کرده لزوماً کاربر پاستیل نیست.

پیشنهاد طراحی: عکس + اسم + نژاد + جنسیت پت، و یک باکس واضح «صاحب این پت» با نام و شماره‌ی مالک + دکمه‌ی تماس مستقیم (tel:). اگه اطلاعات مالک خالی بود، حالت جایگزین ملایم (فقط اسم پت) نشون بده.
